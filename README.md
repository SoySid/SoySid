# Alfredo López (SoySid)

Estudiante de la Licenciatura en Sistemas de Información en la Universidad Nacional del Nordeste (UNNE), Argentina. Desarrollo servicios backend, pipelines de automatización, web scrapers y bots integrados con plataformas de mensajería (WhatsApp y Telegram).

---

## Proyectos destacados

* **[empy-bot](https://github.com/SoySid/empy-bot)**: Bot para WhatsApp desarrollado en TypeScript y Node.js con Baileys. Cuenta con memoria semántica persistente y búsqueda contextual mediante `pgvector` en Supabase (PostgreSQL), un pipeline conversacional de cuatro capas (filtrado heurístico, triage, RAG y modelos de lenguaje con Google Gemini / Gemma y Groq), además de síntesis y clonación de voz neuronal con Fish Audio y un sistema interactivo de economía comunitaria.
* **[llantita-bot](https://github.com/SoySid/llantita-bot)**: Monitor de precios de zapatillas en tiendas de e-commerce de Argentina (Sporting, entre otras). Extrae datos de catálogos periódicamente, guarda el histórico en PostgreSQL (Neon) y envía alertas ante caídas de precio mediante Telegram. Incluye una interfaz web de consulta desarrollada en Next.js.
* **[carrefour-bot](https://github.com/SoySid/carrefour-bot)**: Scraper diario de precios de supermercado construido con Python y Playwright. Se ejecuta de forma programada mediante GitHub Actions para monitorear variaciones de precios y canastas familiares de consumo, persistiendo los datos en PostgreSQL y notificando reportes vía Telegram.
* **Automatización y herramientas**: Desarrollo de scrapers a medida, pipelines de extracción programados con cron o GitHub Actions y utilidades para transformación y limpieza de datos estructurados.

---

## Áreas de trabajo

* **Desarrollo Backend & APIs**: Diseño de servicios desacoplados, modelado de bases de datos relacionales con Prisma ORM, optimización de consultas, caching en memoria y almacenamiento vectorial.
* **Web Scraping & Automatización**: Extracción de datos en sitios dinámicos y SPA mediante navegación headless (Playwright), manejo de selectores resilientes y procesamiento por lotes.
* **Bots & Mensajería**: Conexión a nivel de sockets con clientes de WhatsApp (Baileys) y APIs de mensajería (Telegram Bot API), con control de acceso, manejo de estados y orquestación de tareas en segundo plano.

## Stack técnico

* **Lenguajes**: TypeScript, JavaScript, Python, SQL.
* **Backend**: Node.js, Next.js, Prisma ORM.
