- **Lenguajes:** TypeScript, JavaScript, Python, SQL.
- **Backend & Frameworks:** Node.js, Next.js, Prisma ORM, Express.
- **Bases de datos:** PostgreSQL (Supabase, Neon), SQLite, extensión vectorial `pgvector`.
- **Scraping & Automatización:** Playwright, BeautifulSoup, GitHub Actions, cron.
- **Mensajería & APIs:** Baileys (WhatsApp Web API), Telegram Bot API, Google Gemini, Groq, Fish Audio.
